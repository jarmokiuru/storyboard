# Storyboard

An offline storyboard app for the iPad, modelled on Wonder Unit's Storyboarder: drawing tools, a board strip under scene headings, a 3D shot generator with real lens angles, and contact-sheet PDFs.

- Requirements: [`SPEC.md`](SPEC.md)
- Notes for Claude: [`CLAUDE.md`](CLAUDE.md)
- Test material (generic, not a real production): [`samples/`](samples/)

Status: spec only, build not started.

3D figures and furniture come from Wonder Unit's [shot-generator-models](https://github.com/wonderunit/shot-generator-models) (MIT licence).
